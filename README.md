# Class 12

Predicate logic review for PHIL 270, covering all four parts:

1. Names, predicates, and quantity words
2. Reading formulas and substitution instances
3. All, no, and some
4. Fine-tuned symbolization: quantifier order, moving quantifiers, choosing predicates

Every student gets the same numbered exercises, so the class can work through them together. The 10-minute Candy Challenge at the end awards candy for 8 or more right out of 10.

Students need the class code from their teacher to enter.
