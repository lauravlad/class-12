# Class 12

Predicate logic practice for PHIL 270, about 1 hour 15 minutes:

- Start here: definitions flashcards
- Part 1: Fine-tuned symbolization (looking for things, quantifier order, moving quantifiers)
- Part 2: Identity and counting (at least, exactly, at most, except)
- Part 3: Definite descriptions and properties of relations
- Part 4: Functions and kinds of terms
- Test your knowledge: 10 questions at the end, with a score and review

Every student gets the same exercises in the same order, so the class can work through them together. Progress is saved on each device.

Students need the class code from their teacher to enter.
